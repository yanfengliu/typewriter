# Lessons

Known traps in this repo, newest first. Add one when a problem cost real time and a later session could walk into it again: what happens, why, and what to do instead, with where the evidence is.

- **The in-app browser pane throttles when hidden.** Hidden, it runs `requestAnimationFrame` at about 2 fps and JavaScript several times slower, and a screenshot can show a frame from before your last script ran. Timing, frame rate and "does it keep up" checks must be done in a foreground or headless browser; the Playwright CLI headless on this machine uses the GPU (ANGLE D3D11) and ran this app at 175 fps. In the pane, drive frames yourself with `app.tick(1/60)` and wait a few seconds before a screenshot. Evidence: devlog 2026-11-11.
- **The typist has state the machine snapshot does not hold.** `Typist` remembers that it is holding Shift, which typebar is in flight and whether a return is under way. After `Typewriter.restore` those fingers are gone: call `typist.reset()`, not `clear()`, or the next capital waits forever for a Shift it thinks is already down. Guarded by `tests/typing.test.ts` ("after the machine is restored mid-capital"); red without the reset: stalls with 2 pending after 5 s.
- **Contact flags are state.** `Constraint.active` and `.force` are from the last substep and are read by pre-step logic (a finger decides it has "landed" from `hit.active`). Restoring a snapshot must clear them, or a strike started right after a restore from mid-impact lifts off at once. `Typewriter.restore` clears them; `tests/keystroke.test.ts` ("restoring from the middle of an impact") guards it.
- **Do not model the type impact with XPBD compliance.** Implicit integration damps a 0.3 ms contact numerically (restitution 0.40 instead of 0.55 at 25 µs). Elastic contacts are explicit forces (`Constraint.stiffness`). See `docs/physics.md` section 2 and `tests/solver.test.ts`.
- **A heavy body stopped through light ones needs a direct constraint.** Gauss-Seidel passes the carriage's momentum through the gram-sized wheel and dog a few percent per substep. `holdLoose`/`holdFixed` state the chain's consequence on the carriage itself. Tried and rejected: treating a dog on its stop as pinned (it chattered at the threshold and the carriage buzzed at rest).
- **The escape wheel must not turn backward during carriage return.** With a free wheel the loose dog's spring kicks it back and the carriage settles one column off. The retaining pawl (`backCheck`) and a margin stop that overruns the first column by more than the pawl's backlash fix it; a backlash limit from dog and tooth thickness cannot work, because the loose dog then no longer fits behind the held tooth.
- **Outer typebars reach a dead centre unless each heel is clocked to its own link.** A single heel angle for all 44 bars left the end bars unable to reach the platen. `buildKey` in `src/sim/layout.ts` solves the angle per key.
- **Shell tooling on this machine.** A directory named `build` is write-protected for the agent tools (use another name); a doubled backslash in a heredoc loses one level on the way to the file (so a script that builds source text from it writes a real newline where an escape was meant): put strings with escapes into files with the Edit tool; `tsx -e` and long inline scripts are fragile, put scripts in the scratchpad and run them.
